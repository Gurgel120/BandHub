# BandHub
Um sistema web que permite cadastrar, organizar e consultar bandas e suas músicas


# Nome provisório
BandHub

# Tema do Sistema
Sistema web de cadastro organização, e consulta de informações sobre bandas, suas discografias e integrantes

# Entidade Principal
Bandas

# Principais informações sobre a entidade
Nome, integrantes, gênero musical, ano de formação, prêmios, discografias

# API pública que poderá ser utilizada
MusicBrainzAPI, permite consultar informações sobre artistas, bandas e gravações musicais.
